
# Blackjack Game (Python)

A console-based Blackjack (21) game where the player competes against the computer using standard Blackjack rules.

---

## Key Features

* Player vs computer gameplay
* Blackjack detection
* Ace value handling (11 or 1)
* Computer draws until score ≥ 17
* ASCII logo using `art`

---

## Python Concepts Used

* Functions and return values
* Lists for card management
* Loops and conditional logic
* Randomization with `random`
* User input handling
* External module usage (`art`)
